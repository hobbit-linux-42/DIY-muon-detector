# DIY muon detector

## the project
We have carried out an amateur experiment to detect muons, particles from space. To do this, we disassembled a webcam, isolating the sensor and covering it completely with aluminium and adhesive tape to prevent light from entering, while allowing high-energy particles to pass through. After connecting the webcam to the computer, we noticed some background noise due to the USB connection, but not enough to compromise the experiment. We then used the Theremino Particle Detector program to record high-energy signals via long exposures. After about 20 hours of recording, we were able to detect an event compatible with a muon, although the operation was difficult due to the small size of the sensor.
To verify that it was not simple environmental radioactivity, we compared the signal with that produced by a source of alpha particles (uranium glass), noting that these produced weaker signals of different shapes. This comparison strengthens the hypothesis that the first event was indeed a muon. Finally, we processed the images with GIMP to improve their quality and also obtain a possible three-dimensional model. We conclude by emphasising the commitment and enthusiasm with which we carried out the experiment, even at the cost of staying awake for a long time to monitor the data.

## this repo
In the repository there are two folders,
the "Measurements" folder and the "Photos" folder.

In the photos folder you can see images of the experiment
While In the "Measurements" folder there are three
different subfolders:
    - "muons" showing the measured muons,
    - "models" which shows the 3D models obtained
      from images by using them as hight maps,
    - "uranium" showing the measurements made
       with a radioactive sample near the detector,
       and which therefore shows alpha particles.
       
## materials used
    - a webcam
    - black insulating tape
    - alluminium foil
